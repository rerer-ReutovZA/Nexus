# Nexus — The Ultimate Network Shield

Универсальный инструмент для Windows, объединяющий возможности **Telegram WS-прокси**, движка **Zapret** (обход DPI) и полноценного **VPN-ускорителя** в одном интуитивно понятном интерфейсе.

---

## 🚀 Что нового в версии 3.0.0 "Plugin Era"

Версия 3.0.0 — это глобальное обновление, которое превращает Nexus из утилиты в полноценную платформу:
- **Plugin System**: Масштабируемая архитектура для добавления новых функций.
- **Internet Accelerator**: Полноценный VPN-клиент на базе Sing-box (VLESS/Reality).
- **TUN Mode**: Системный VPN-адаптер для ускорения всех игр и программ без настройки прокси.
- **Telegram Remote**: Управление всеми функциями (статус, Zapret, Ускоритель) прямо с телефона.

## Основное описание

Nexus предоставляет удобную графическую оболочку для управления ключевыми сетевыми компонентами:

*   **Telegram WS-прокси:** Локальный релей, позволяющий Telegram Desktop и его модификациям стабильно работать в условиях сетевых ограничений. Ссылка для подключения генерируется автоматически.
*   **Zapret (Обход DPI):** Полноценная интеграция `winws.exe` и драйвера `WinDivert`. Включает в себя проверенные стратегии для восстановления доступа к Discord и YouTube.
*   **Ускоритель (VPN):** Современный клиент с поддержкой подписок VLESS/Reality, автоматическим пингом серверов и разделением трафика по процессам.

## 🛠 Система плагинов (Plugin System)

Nexus теперь поддерживает пользовательские плагины, которые позволяют расширять возможности программы без изменения её кода.

### Как установить плагины
1. Откройте Nexus и перейдите во вкладку **«Плагины»**.
2. Скопируйте путь к папке плагинов (указан в интерфейсе).
3. Поместите папку с плагином (из каталога `plugins` репозитория) в эту директорию.
4. Нажмите **«Обновить список»** и включите плагин.

### Создание своего плагина
Каждый плагин представляет собой папку с двумя файлами:
- `manifest.json`: Метаданные (название, версия, автор).
- `index.js`: Основная логика на JavaScript (ESM).

#### Доступные инструменты в `context`:
- `context.log(message)`: Запись в системные логи Nexus.
- `context.on(event, callback)`: Слушатель событий системы (`zapret:status`, `tgws:status`).
- `context.getAppConfig()` / `context.patchAppConfig(patch)`: Управление настройками.
- `context.startZapret()` / `context.stopZapret()`: Управление Zapret.
- `context.startSingbox()` / `context.stopSingbox()`: Управление Ускорителем.
- `context.readHosts()` / `context.writeHosts(content)`: Безопасное управление файлом hosts.

## Технологии

*   **Frontend:** React 19, Vite, Tailwind CSS v4, Lucide. 
*   **Backend:** Electron 37 (TypeScript).
*   **Cores:** winws (Zapret), Sing-box (Accelerator), TgWsProxy (Telegram).

## Инструкции

### Для разработчиков

1.  Установите зависимости: `pnpm install`
2.  Запустите в режиме разработки: `pnpm dev`

### Для пользователей (Сборка)

Сборка готового инсталлятора: `pnpm build:win`
