# Nexus

Универсальный инструмент для Windows, объединяющий возможности **Telegram WS-прокси** и движка **Zapret** (обход DPI) в одном интуитивно понятном интерфейсе.

## Основное описание

Nexus предоставляет удобную графическую оболочку для управления двумя ключевыми сетевыми компонентами:

*   **Telegram WS-прокси:** Локальный релей, позволяющий Telegram Desktop и его модификациям стабильно работать в условиях сетевых ограничений. Ссылка для подключения генерируется автоматически и может быть передана в клиент одним нажатием.
*   **Zapret (Обход DPI):** Полноценная интеграция `winws.exe` и драйвера `WinDivert`. Приложение включает в себя проверенные временем стратегии для восстановления доступа к популярным сервисам, таким как Discord и YouTube.

Программа обеспечивает автоматический перезапуск сервисов при сбоях, поддержку работы в системном трее и возможность автозапуска вместе с Windows.

## Ключевые особенности

*   **Минималистичный дизайн:** Управление всеми функциями через единую главную кнопку и наглядные индикаторы состояния.
*   **Гибкое обновление:** Встроенные механизмы проверки новых версий Zapret и TgWsProxy позволяют поддерживать актуальность инструментов в один клик.
*   **Безопасность и приватность:** Уникальные ключи шифрования генерируются локально для каждой установки. Ваши настройки и секреты никогда не покидают компьютер.
*   **Портативность:** Поддержка работы в переносном режиме без записи данных в системные папки (при наличии файла-маркера `PORTABLE`).
*   **Локализация:** Полная поддержка русского и английского языков интерфейса.

## Технологии

*   **Frontend:** React 19, Vite, Tailwind CSS v4, Lucide.
*   **Backend:** Electron 37 (TypeScript).
*   **Сборка:** electron-builder, NSIS, PyInstaller.

## Инструкции

### Для разработчиков

1.  Установите зависимости: `pnpm install`
2.  Запустите в режиме разработки: `pnpm dev`

### Для пользователей (Сборка)

Сборка готового инсталлятора выполняется командой:
`pnpm build:win`

После завершения в папке `dist` появятся:
*   `Nexus_x64.exe` — стандартный установщик (требуются права администратора).
*   `Nexus_x64-portable.7z` — версия, не требующая установки.
