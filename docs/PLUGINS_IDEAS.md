# Идеи плагинов для Nexus

Этот список содержит концепции плагинов, которые можно реализовать в системе плагинов Nexus.

## 1. Автоматизация (Smart Logic)
- **Game Trigger**: Автоматическое переключение на игровой профиль (низкий пинг) при запуске определенных .exe (Roblox, Dota 2, Steam).
- **Night Shift**: Автоматическая смена темы на ночную и включение режима "Максимальный обход" по расписанию (например, с 23:00 до 08:00).
- **Auto-Fixer**: Автоматический перезапуск сервисов или смена стратегии, если проверка доступности YouTube/Discord не проходит в течение 5 секунд.

## 2. Сетевые функции (Network)
- **DoH / DNS-Crypt**: Плагин для шифрования DNS-запросов (Cloudflare, Google), защищающий от подмены DNS провайдером.
- **Ad-Blocker**: Глобальная блокировка рекламных доменов на уровне системы через Nexus.
- **Twitch Fixer**: Специальная оптимизация параметров фрагментации пакетов для серверов Twitch, устраняющая лаги в 4K.

## 3. Интеграции (Integrations)
- **Discord Rich Presence**: Отображение статуса Nexus (режим, скорость трафика) в игровом профиле Discord.
- **Telegram Remote Bot**: Создание бота для управления Nexus с телефона (команды /status, /restart, /switch).
- **OBS Status Overlay**: Веб-виджет для стримеров с текущим статусом обхода.

## 4. Визуальные эффекты (Visuals)
- **Matrix Dashboard**: Визуализация трафика в виде падающих символов а-ля Матрица.
- **Sound Engine Pack**: Дополнительные наборы звуковых эффектов (Sci-Fi, Retro, Minimalist).
- **Ambilight Sync**: Синхронизация цветов интерфейса с доминирующим цветом на экране.

## 5. Расширения движков (Engine Extensions)
- **Sing-box Engine**: Добавление поддержки ядра Sing-box как альтернативы Zapret.
- **Xray Integration**: Вкладка для управления VLESS/Reality прокси внутри Nexus.
